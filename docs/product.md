# ReviewFault v0.3 产品定义

## 目标

帮助考研学生把“何时复习”和“今天复习什么”的决策交给软件，同时针对数学与 408 提供不同的学习动作。默认离线可用、数据归用户所有；网络同步不是记录与复习的前置条件。

## 数学：错题本不是图片仓库

一次数学错题记录应尽量在 30 秒内完成。首版最短路径为“拍题或一次选择 1–5 张截图 → 可选填写来源 → 保存”，答案、错误步骤、错因和复盘稍后补充。自动裁边与 OCR 是后续增强，不能成为保存题面的前置条件。

每道题包含：

- 题面：一张或多张图片，也可补充 LaTeX/文本；
- 来源：书目、页码、题号、考试年份，可选；
- 章节与标签；
- 错因：概念不清、思路中断、计算错误、审题错误、遗忘结论、超时、其他；
- 首次作答、重做记录、耗时、信心和结果；
- 正解、自己的关键错误步骤、下次看到题时需要想起的一句提示；
- 后续可由一道题拆出“方法卡/结论卡”用于记忆，但原题本身始终以重做为主。

复习时先只显示题面并计时。用户提交“不会 / 做错 / 勉强做对 / 熟练”后再显示解答和历史错误。做错后快捷选择错因；查看提示后最高只能记为“勉强做对”。算法根据结果安排下一次重做，计算/审题/超时与概念类错误使用不同重做间隔。

## 408：以主动回忆为中心

408 笔记使用以下模板，而不是只有正反面文本：

- 问答卡：定义、原因、区别、步骤；
- 填空卡：适合协议字段、公式和关键术语；
- 分层提示卡：先回答，再逐层展开提示；
- 枚举卡：答案为无序要点，按命中要点评分；
- 图示遮挡：适合数据结构、报文、状态机与体系结构图；
- 对比卡：例如进程/线程、TCP/UDP；
- 关联卡：知识点之间建立先修、相似、易混关系。

作答阶段强制先回忆再显示答案。评分采用四档：忘记、困难、正确、轻松。可记录文字或语音草稿，但不要求逐字匹配标准答案。

## 今日队列

首页把任务分成“到期复习”“今天新学”“逾期”三组，并显示预计用时。默认优先级：逾期的短复习、到期 408、到期数学重做、用户设定的新内容上限。用户可按科目、章节和剩余时间筛选；跳过不会被计为作答失败。

## 题库与设置

题库支持防抖搜索、分页、科目/类型/标签/状态筛选与批量选择。编辑覆盖两类内容的
结构化字段。删除写墓碑，提供短时撤销和回收站批量恢复；不永久清除媒体或历史。

学习设置随 SQLite 备份：每日新 408 上限、单次时长、启用科目/队列、408 记忆预设、
数学强度。主题、提醒时间、星期与通知权限是设备设置。提醒默认关闭，开启时才申请权限，
且只在存在待复习内容时发本地通知。

## v0.3 验收标准

- 不联网也能新建、编辑、搜索、复习和查看统计；
- 同一学习历史在 Android、Windows 上计算出相同的下次复习时间；
- 408 支持问答、填空、枚举和分层提示四种模板；
- 数学支持相机/截图录入、多图题面、错因、解答和完整重做历史；
- 每次评分按当前灰度开关生成不可变 v2 或 v3 事件；从复习页删除会结束会话且不生成评分、attempt 或事件；
- 时区变化不会改变已经确定的绝对到期时刻；“今日”按用户当前时区展示；
- 数据可以完整导出；v0.3 可恢复 v1/v2/v3，旧备份恢复后自动顺序迁移。
