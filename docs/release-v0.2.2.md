# ReviewFault v0.2.2

这是开始日常使用前的一轮稳定性与细节打磨版本，schema、调度 ABI 和备份协议均保持 v2。

## 主要变化

- “今日”只统计当前设置下真正可学习的任务，并正确扣除当天已经学习的新 408 数量；
- 三端队列现在会应用启用科目、408/数学类型开关和每日新 408 上限；达到 408 上限后，数学新题仍可继续重做；
- Android 设置页补齐队列类型和 408 科目开关，题库筛选会显示当前选中状态；
- Android 复习提交增加防重复保护，评分后立即刷新首页统计，并稳定保留“下次复习”反馈；
- 修正删除撤销超时提示，恢复和设置操作不再遗留错误的撤销入口；
- 三端恢复都会拒绝超大、重复、非法或未在清单声明的备份文件，失败时保留原数据；
- Android 明确关闭系统云备份和设备迁移，继续以可校验的 `.reviewfault` 文件作为唯一完整备份路径；
- Android 发布资产改为持久证书签名的 release APK，后续版本可直接覆盖安装并保留本地数据；
- 增加跨平台真实 SQL 队列契约测试和版本一致性门禁。

## 下载与升级

- Android：安装 `ReviewFault-android-v0.2.2.apk`，最低 API 26；从旧 debug 包切换到正式签名时，如系统提示签名不一致，请先在旧版导出 `.reviewfault`，再安装新版并恢复；
- Windows：解压 `ReviewFault-windows-v0.2.2-x64.zip` 后运行，支持 Windows 10 1809 或更高；
- HarmonyOS：安装 `ReviewFault-harmony-v0.2.2.hap`，需要 HarmonyOS 5.0.1（API 13）或更高版本；

首次开始长期使用前，建议先做一次空库备份/恢复演练；之后在大量录入或跨版本升级前导出一份 `.reviewfault`。
