# ReviewFault v0.6.1

这是一次 Android 学习入口与制卡体验更新，schema、调度 ABI 和备份协议继续保持 v5，现有数据无需迁移。

## 首次学习与首页

- 首页为等待首次学习的内容提供独立入口，不再依赖专注轮次是否允许混入新内容；
- 只有新内容时，主按钮会直接进入首次学习；复习和新内容同时存在时，两条路径都会明确显示；
- 学习负载预报改为上下结构和等宽指标，窄屏不再把右侧统计压成竖排。

## 渐进制卡与标签

- 408 知识卡只需回忆问题和核心答案即可保存；评分要点、提示、理解、迁移、来源和标签按需逐步展开；
- 科目、知识形式、来源类型和错因等固定选项改为下拉菜单；
- 标签仍由用户自由输入，并会记住已有标签，输入前缀时提供补全候选。

## 应用内更新

- Android 设置页新增检查更新、下载安装包和发起系统安装流程；
- 更新来源固定为 ReviewFault 官方 GitHub Release，并校验版本对应的 APK 名称和下载地址；
- Android 首次使用应用内安装时，需要按系统提示授予“安装未知应用”权限，最终安装仍由系统确认。

## 安装

- Android：安装 `ReviewFault-android-v0.6.1.apk`，最低 API 26，可从使用相同发布证书的旧版本覆盖升级并保留本地数据；
- Windows 与 HarmonyOS 同步版本号至 0.6.1，本次交付沿用 v5 数据契约。
