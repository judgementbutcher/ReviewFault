# ReviewFault v0.3.1

这是一次面向“每天更容易坚持”的间隔学习体验更新。schema、调度 ABI 与备份协议继续保持 v3，
已有数据和 v1/v2/v3 备份完全兼容。

## 主要变化

- 新增专注轮次：按设置中的单次学习时长开始，达到目标后自然收尾并返回首页；
- 新增积压保护：时间预算装不下全部到期内容时，本轮不再引入新内容，优先消化既有复习；
- 首页区分本轮预计时长与尚未装入本轮的到期负载，长队列不再伪装成一次必须清空的任务；
- 新增明日与未来 7 天负载预报，便于提前发现复习波峰；
- 共享核心增加可测试的 1–31 天负载预测与延后用时统计，Android/Windows 使用一致的队列契约；
- 保留全部 v2/v3 调度黄金样例，升级队列算法不会改写历史事件或已确定的到期时间。

## 安装

- Windows（推荐）：下载并运行 `ReviewFault-windows-v0.3.1-x64.msi`；
- Windows（便携）：下载 `ReviewFault-windows-v0.3.1-x64.zip`；
- Android：安装 `ReviewFault-android-v0.3.1.apk`，最低 API 26。

所有发布资产的 SHA-256 见 `SHA256SUMS`。升级前仍建议导出完整备份。
