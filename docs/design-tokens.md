# v0.6 中性暗黑视觉与无障碍 token

三端默认采用中性灰黑语义 token：背景 `#090A0C`，表面 `#121417`，
抬升表面 `#181B1F`，正文 `#F2F4F7`，次级正文 `#A7ADB5`，描边 `#2A2E34`。
`#D4F36A` 只用于当前状态、主要提交和数据增长；错误使用 `#E06C75`，其余状态同时提供文字或图形信号。
页面区块使用实色表面，不依赖渐变、玻璃模糊或装饰性光球；阴影保持克制，避免把内容层叠成卡片套卡片。

主要面板和重复内容圆角不超过 8，内容间距基于 4 的倍数；普通交互最小高度 48dp/epx，Windows 为
44 effective px。正文不锁死行高并跟随动态字体。图片、评分、删除、恢复、导航和输入框
必须提供屏幕阅读器名称；颜色不是状态的唯一表达。移动端底部导航为“今日、洞察、题库、
添加、设置”，桌面端使用左侧 NavigationView；专注复习页不展示干扰性批量操作。

页面切换采用短时淡入/位移动效，选择状态使用 180–240ms 的颜色与描边过渡；柱状图使用 350–450ms 的高度增长动效。
动效只表达层级和数据变化，不循环闪烁，不阻塞操作，并服从平台减少动态效果设置。
