# v0.2 视觉与无障碍 token

三端使用语义 token，不以页面硬编码含义：背景米白 `#F7F5EF`、主品牌深绿 `#315C49`、
标题绿 `#1E362B`、亮色表面 `#FFFFFF`；暗色对应背景 `#111814`、表面 `#1B251F`、
标题 `#D8E8DE`。错误、警告、成功分别使用平台可访问的 error/amber/green 语义色。

卡片圆角 12–14，内容间距基于 4 的倍数；普通交互最小高度 48dp/epx，Windows 为
44 effective px。正文不锁死行高并跟随动态字体。图片、评分、删除、恢复、导航和输入框
必须提供屏幕阅读器名称；颜色不是状态的唯一表达。移动端底部导航为“今日、题库、添加、
设置”，桌面端使用左侧 NavigationView；专注复习页不展示干扰性批量操作。
