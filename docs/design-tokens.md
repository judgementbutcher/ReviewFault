# v0.5 现代暗黑视觉与无障碍 token

三端默认采用现代暗黑语义 token：深空背景 `#07110F`，玻璃表面 `#101C19`，
高对比正文 `#E5F0EC`，次级正文 `#B7C9C3`，薄荷主色 `#78E8C1`，
柔紫辅色 `#C9B8FF`，琥珀提醒 `#FFC66C`。玻璃表面应使用 72%–86% 不透明度、
1px 低对比描边和平台原生模糊/Acrylic 能力；不支持模糊时回退到实色表面。

主要面板圆角 20–26，次级控件圆角 12–18，内容间距基于 4 的倍数；普通交互最小高度 48dp/epx，Windows 为
44 effective px。正文不锁死行高并跟随动态字体。图片、评分、删除、恢复、导航和输入框
必须提供屏幕阅读器名称；颜色不是状态的唯一表达。移动端底部导航为“今日、洞察、题库、
添加、设置”，桌面端使用左侧 NavigationView；专注复习页不展示干扰性批量操作。

页面切换采用淡入，玻璃卡片可使用轻微错峰进入；柱状图使用 350–450ms 的高度增长动效。
动效只表达层级和数据变化，不循环闪烁，不阻塞操作，并服从平台减少动态效果设置。
