# ReviewFault v0.3.0

这是“可回放、可度量、可迁移”的后端与间隔学习升级版本。schema、调度 ABI 和备份协议均升级到
v3；v1/v2 数据、备份与历史调度入口继续兼容，已有事件不会被改写。

## 主要变化

- 新增匿名本地回放评估命令，输出召回率、遗忘次数、日负载峰值、间隔分布和 Brier 校准误差；
- 新增参数注册表、校验和、决策快照、客户端时区偏移与作答耗时质量；
- 408 调度区分短步骤和长期复习，对逾期卡及连续遗忘增加保护；只有历史达到 200 条且校准改善
  至少 0.01 时才允许使用个人参数；
- 数学调度区分概念/思路与计算/审题/超时错误，连续失败优先，连续独立熟练逐步拉长间隔；
- Android 和 Windows 均提供“使用 v0.3 调度”开关，可随时继续使用冻结的 v0.2 参数；
- v3 备份继续恢复 v1/v2，恢复会先迁移临时数据库并完成完整性、外键和哈希校验后再替换当前数据。

## 安装

- Windows（推荐）：下载并运行 `ReviewFault-windows-v0.3.0-x64.msi`；支持 Windows 10 1809 或更高；
- Windows（便携）：下载 `ReviewFault-windows-v0.3.0-x64.zip`，完整解压后运行 `ReviewFault.exe`；
- Android：安装 `ReviewFault-android-v0.3.0.apk`，最低 API 26。

所有发布资产的 SHA-256 见 `SHA256SUMS`。升级前建议先导出完整备份；v0.3.0 可以直接恢复 v1、
v2、v3 备份。
