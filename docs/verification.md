本轮已在宿主环境运行 `make test`、Windows 仓储集成测试、Linux 上的 WinUI 托管编译，
以及 Android arm64-v8a/x86_64 debug/release 构建与 lint；正式 APK 的版本号和持久证书指纹也已校验。

通过后才允许生成 tag 资产。正式 Android 资产由仓库持久证书签名，Windows 原生包由 Windows
runner 生成。API 26/35、Windows 10/11 以及两端互恢复仍需设备验收。
