# ReviewFault v0.2.1

本版本集中解决 Android 端添加内容后界面风格突变、首页操作拥挤和产品完成度不足的问题。

## 主要变化

- 修复数学错题或 408 卡片保存后进入旧版首页的问题，所有流程现在都会返回统一的应用壳；
- 重构“今日”首页，按照任务状态只保留一个明确的主行动，并增加空状态引导；
- 建立统一的浅色/深色语义色、圆角、间距、排版与组件层级；
- 添加页面改为两条低摩擦记录路径，备份与恢复从首页移入设置；
- 设置按学习、外观、提醒、数据分组并渐进展开，降低单屏信息密度；
- 复习页进入无底栏的专注模式，支持分层提示、题面图片、答案阶段和清晰评分；
- 增加页面切换、内容展开、任务数字和导航出现/隐藏动效；
- 优化题库搜索、空状态、选择反馈以及动态字体下的横向选项浏览。

## 下载

- Android debug APK：最低 API 26；
- Windows x64 ZIP：解压后运行，Windows 10 1809 或更高；
- HarmonyOS：版本元数据已同步，签名 HAP 仍需组织的 DevEco/HarmonyOS runner 生成。

本版本不修改 schema v2、调度 ABI v2 或备份协议 v2。所有发布资产的 SHA-256 见 `SHA256SUMS`。
