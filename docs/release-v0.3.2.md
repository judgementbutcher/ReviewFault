# ReviewFault v0.3.2

这是一次补齐专注轮次安全退出路径的体验更新。schema、调度 ABI 与备份协议继续保持 v3，
已有数据以及 v1/v2/v3 备份完全兼容。

## 主要变化

- Android 与 Windows 复习页新增“本轮跳过（不评分）”；
- 跳过的内容在当前轮次内不再重复出现，开始下一轮后会按原到期时间重新进入队列；
- 跳过不修改到期时间、调度状态或历史，也不生成评分、数学 attempt 或 v2/v3 复习事件；
- 新增“提前结束本轮”，关闭、时间预算到达、队列耗尽与全部候选被跳过时统一返回今日页；
- 本轮总结同时展示已完成数量、跳过数量与实际用时；
- 两端下一条查询使用相同的完整 ID 边界排除规则，并新增 SQL 与仓储集成回归测试。

## 安装

- Windows（推荐）：下载并运行 `ReviewFault-windows-v0.3.2-x64.msi`；
- Windows（便携）：下载 `ReviewFault-windows-v0.3.2-x64.zip`；
- Android：安装 `ReviewFault-android-v0.3.2.apk`，最低 API 26。

所有发布资产的 SHA-256 见 `SHA256SUMS`。升级前仍建议导出完整备份。
