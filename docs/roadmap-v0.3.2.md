# v0.3.2 可控专注轮次开发计划

> 状态：已完成。实现证据见双端会话排除查询与交互、跨端队列契约、Windows 仓储集成测试、
> Android 构建/lint 以及 `docs/release-v0.3.2.md`。schema、调度 ABI 与备份协议继续保持 v3。

## 背景与目标

v0.3.1 已能按时间预算组织专注轮次并保护到期积压，但当前 Android 与 Windows 客户端只能
评分、删除或直接离开当前题目。产品定义要求“跳过不会被计为作答失败”，因此下一补丁聚焦补齐
安全退出路径：用户可以暂时跳过不适合当下完成的内容，也可以提前结束一轮，并清楚看到本轮结果。

本次迭代不调整到期时间、不改变调度参数，也不新增持久化会话状态。跳过仅在当前专注轮次内
生效；下一轮仍按原有绝对到期时间重新进入队列。

## 1. 会话内无评分跳过

- Android 与 Windows 的复习页都提供“本轮跳过（不评分）”操作；
- 跳过后当前内容在同一轮内不再出现，直到开始下一轮；
- 跳过不更新 `study_item`、类型化调度状态或到期时间，也不写入 `attempt`、`review_log`、
  `review_event_v2` 或 `review_event_v3`；
- 跳过所花时间计入本轮用时，但不计入已复习数量；
- 当剩余内容都已跳过时，自然结束本轮，避免重复弹出同一条内容。

## 2. 提前结束与结果总结

- 复习页提供明确的“提前结束本轮”入口，关闭按钮使用同一结束语义；
- 正常达到时间预算、队列耗尽、全部剩余内容被跳过或用户主动结束时，都返回今日页；
- 总结至少展示已评分数量、跳过数量和本轮用时；没有评分时也不伪造完成记录；
- 从复习页删除内容仍按既有契约结束会话，且不生成评分、attempt 或事件。

## 3. 跨端队列契约

- 两端仓储的“下一条”查询接收当前会话排除集，并在排序前过滤这些 ID；
- 排除集只存在于内存，不进入 SQLite、备份或跨设备数据；
- 空排除集保持 v0.3.1 的队列顺序、每日新内容上限和积压保护行为；
- 使用固定格式编码排除 ID，并拒绝会破坏边界匹配的非法 ID，避免前缀误匹配。

## 4. 验证与回归门禁

- 扩展跨端队列契约测试：首项被排除后选择下一项，全部候选被排除后返回空；
- 扩展 Windows 仓储集成测试：排除查询不写复习事件，下一轮清空排除集后内容重新可见；
- 平台源码契约同时检查两端存在跳过和提前结束入口；
- 运行 `make test`、Windows 仓储集成测试、Android debug 构建与 lint、Windows 托管编译；
- 发布工作流继续要求 Android release 签名校验、Windows 自包含 ZIP 与 MSI 安装/卸载冒烟测试。

## 5. 版本与发布

- 将应用、安装器、工作流、版本契约和 README 同步到 `0.3.2`；
- 新增 `docs/release-v0.3.2.md`，说明跳过只影响当前轮次且不会移动到期时间；
- 所有验证通过后提交发布变更，创建并推送 `v0.3.2` tag；
- 等待 GitHub Actions release 工作流完成，并核验 APK、MSI、便携 ZIP 与 `SHA256SUMS`。

## 非目标

本补丁不实现评分撤销、跨重启恢复未完成轮次、手动改期、永久清除、图示遮挡编辑器、OCR、
云同步或跨设备自动同步；这些能力需要独立的数据与交互设计，不能借“跳过”隐式改变历史。
