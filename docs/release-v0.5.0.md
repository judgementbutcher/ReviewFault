# ReviewFault v0.5.0

v0.5.0 把“看见长期积累”带进 ReviewFault，并将三个原生客户端统一为现代暗黑视觉。本次正式发布 Android 与 Windows；HarmonyOS 同步完成同版本功能与界面开发，签名 HAP 仍通过可选的专用 Runner 构建。

## 数据洞察

- 新增独立“洞察”入口，Android、Windows、HarmonyOS 使用同一组本地指标；
- 近 7 日复习活跃度柱状图，展示每天实际完成的复习次数；
- 未来 7 日负载柱状图，展示已经排定的到期内容；
- 今日复习、近 7 日正确率、连续学习天数与累计复习次数；
- 知识库熟练进度：至少复习 3 次且稳定度达到 14 天的内容计为熟练；
- 学科分布展示各科内容量和熟练占比，数据不离开设备。

正确率只作为近期复习反馈的概览：408 的“正确/轻松”和数学的“勉强做对/熟练”计入成功，不用于改写历史评分或调度结果。

## 现代暗黑界面

- 默认使用深空暗黑背景、薄荷与柔紫强调色；
- 内容面板使用半透明玻璃表面、细描边和更大的圆角；
- Android 增加渐变氛围光与页面淡入，Windows 使用 Acrylic 回退安全的玻璃卡片；
- 数据柱状图使用自然的高度增长动效，保持文字标签和数值，不以颜色作为唯一信息；
- HarmonyOS 同步暗黑启动页、导航、复习画布和数据面板。

## 兼容性

- schema 仍为 v4，调度 C ABI 仍为 v4，调度算法参数仍为 v3；
- 备份协议仍为 v4，v0.4.0 的本地数据库与备份可直接继续使用；
- Android `versionCode` 与 HarmonyOS `versionCode` 同步提升到 10；
- Windows 支持 Windows 10 1809 或更高版本，Android 最低 API 26。

## 安装

- Android：安装 `ReviewFault-android-v0.5.0.apk`，持久发布证书支持从 v0.4.0 覆盖升级；
- Windows：优先使用 `ReviewFault-windows-v0.5.0-x64.msi`，也提供自包含便携 ZIP；
- HarmonyOS：本次不作为正式发布附件；源码、版本号和签名构建门禁已同步到 v0.5.0。
